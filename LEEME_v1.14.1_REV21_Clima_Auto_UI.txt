OneHouse v1.14.1 - REV21 Clima Auto + UI
Base: REV20 FIX UI Final (compilada y validada por el usuario)

CAMBIOS
1. Climatización - AUTO
   - Revisado el flujo actual de Auto en REV20.
   - OneHouse ya envía Auto como valor 0 por la GA de modo 5/2/4 (DPT 20.105).
   - El estado 5/3/4 ya interpreta valor 0 como Auto.
   - Home ya muestra "Auto" cuando ese es el estado confirmado por KNX.
   - Se conserva esta lógica para no introducir una automatización paralela ni romper los modos Frío/Calor/Vent./Dry.
   - El ETS contiene además objetos 1-bit específicos de Auto; no se añaden a la carga inicial ni se fuerzan en esta REV sin una prueba real que confirme que deban sustituir el modo HVAC existente.

2. Climatización - datos ambientales
   - Eliminada la cápsula de tiempo exterior de la cabecera.
   - El panel inferior pasa de Humedad | CO2 a Exterior | Humedad | CO2.
   - Exterior conserva el mismo dato meteorológico que ya utilizaba OneHouse.

3. Home - icono Terraza
   - La estancia favorita Terraza ya no muestra una raya cuando todavía no existe evento de lluvia.
   - Sin lluvia/evento pendiente muestra sol; con lluvia real muestra lluvia.
