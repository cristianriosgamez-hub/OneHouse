OneHouse v1.13.2 - Restauración segura y validada
====================================================

Objetivo
--------
Blindar la restauración de copias antes de modificar la configuración activa de OneHouse.

Cambios
-------
- Validación profunda del JSON antes de mostrar la confirmación de restauración.
- Se comprueba formato, schema, tamaño y estructura de cada bloque de preferencias compatible.
- Se decodifican todos los valores antes de escribir nada para detectar tipos o datos corruptos.
- Las direcciones global_* del backup KNX se validan con el formato y rangos KNX X/X/X.
- app_project_copy debe existir con contenido válido cuando viene incluido.
- Los bloques históricos de InsideControl/importador y cualquier bloque desconocido se ignoran y se muestran como aviso.
- Las claves KNX antiguas/no soportadas se ignoran y se contabilizan como aviso.
- La pantalla de confirmación muestra esquema, bloques compatibles y resultado de validación.
- Antes de restaurar se repite la validación para proteger frente a cambios/corrupción entre preview y confirmación.
- Se conserva el rollback transaccional ya existente: si cualquier escritura falla, se restaura automáticamente el estado anterior.
- Tras restaurar KNX se vuelve a aplicar la depuración OneHouse y se eliminan fuentes históricas del importador.
- No se añaden llamadas KNX ni se modifica el motor de carga/reconciliación.

Versión
-------
versionCode: 127
versionName: 1.13.2 Restauración segura y validada

Prueba recomendada
------------------
1. Compilar e instalar.
2. Seleccionar el backup validado de v1.13.1.
3. Comprobar que el diálogo indica Validación: OK, esquema 2 y 36 estados KNX activos.
4. Restaurar.
5. Reiniciar OneHouse y comprobar carga KNX 100% y 36 estados resueltos.
6. Opcional: probar un JSON dañado y confirmar que se rechaza antes de sobrescribir datos.
