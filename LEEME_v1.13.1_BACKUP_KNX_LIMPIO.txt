OneHouse v1.13.1 - Backup KNX limpio y coherente con OneHouse
==============================================================

OBJETIVO
--------
Blindar las copias de seguridad para que solo incluyan la configuración KNX que
pertenece realmente a OneHouse y nunca vuelvan a introducir objetos históricos
del antiguo proyecto/importador InsideControl.

CAMBIOS
-------
1. El backup general deja de exportar completamente:
   - insidecontrol_import
   - import_project_ui
   Son fuentes históricas del importador y no forman parte del modelo activo.

2. La configuración onehouse_knx_configuration se exporta con lista blanca:
   - Proyecto activo de OneHouse ya depurado por OneHouseKnxUsagePolicy.
   - Direcciones globales definidas actualmente en KnxAddressBook.
   - Parámetros vigentes de velocidades de climatización.
   - NO se exporta automatic_backup, porque podría contener fotografías antiguas.

3. Antes de crear una copia se fuerza la depuración silenciosa del proyecto KNX.

4. Restauración protegida:
   - Backups nuevos usan esquema 2.
   - Se siguen aceptando backups esquema 1.
   - Si un backup antiguo trae datos InsideControl/importador, se ignoran.
   - Las claves KNX antiguas no incluidas en la lista blanca se descartan.
   - Tras restaurar se vuelve a aplicar OneHouseKnxUsagePolicy.
   - Al restaurar configuración KNX nativa se limpian los datos históricos del
     importador para impedir que objetos eliminados vuelvan a poblar OneHouse.
   - Existe rollback de preferencias actuales si la restauración falla.

5. La pantalla de Backup indica que solo guarda configuración KNX activa.
   En el resumen de los backups nuevos muestra el número de estados/direcciones
   KNX activos calculado con la misma selección usada por la carga inicial.
   En la configuración actual debería reflejar las 36 direcciones activas de
   OneHouse (si no se cambia la configuración KNX).

6. Versión actualizada a:
   versionCode 126
   versionName 1.13.1 Backup KNX limpio

PRUEBAS RECOMENDADAS
--------------------
1. Compilar proyecto.
2. Abrir Más > Herramientas > Backup y restauración.
3. Crear un backup JSON.
4. Seleccionarlo para restaurar y comprobar que el resumen muestra 36 estados KNX
   activos (con la configuración actual).
5. Restaurar la copia y reiniciar OneHouse.
6. Comprobar carga KNX 36/36 y funcionamiento de luces, persianas, clima y sensores.
7. Confirmar que el rendimiento conseguido en v1.13.0.x se mantiene.

NOTA DE COMPILACION
-------------------
No se ha podido ejecutar compileDebugKotlin en el entorno de generación porque el
wrapper necesita descargar Gradle 9.5.0 desde services.gradle.org y este entorno
no dispone de acceso de red. El usuario debe validar la compilación en Android Studio.
