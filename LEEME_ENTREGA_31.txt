ONEHOUSE - ENTREGA 31 - v1.6.1 CONEXIÓN HOME ASSISTANT
Base utilizada: OneHouse 1.6.0 Seguridad visual.zip

CAMBIOS
- Configuración de dirección local de Home Assistant.
- Campo para token de acceso de larga duración.
- Token cifrado mediante Android Keystore antes de guardarse.
- Botón "Guardar y comprobar".
- Prueba real contra el endpoint /api/ de Home Assistant.
- Estados: Sin configurar, Sin comprobar, Comprobando, Conectado y Sin conexión.
- Mensajes específicos para token inválido, URL incorrecta y errores de red.
- Se permite HTTP local para instalaciones Home Assistant dentro de la vivienda.
- Versión actualizada a 1.6.1 (versionCode 26).

NO MODIFICADO
- KNX, direcciones de grupo, luces, persianas, climatización, consumos y estancias.
- Todavía no se leen entidades Xiaomi; este paso deja preparada y verificada la conexión.
